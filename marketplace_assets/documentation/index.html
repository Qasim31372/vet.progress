Project Overview

Vet Learn Hub is a full-featured veterinary clinical learning, case recording, and medical management system. It provides three strictly isolated roles:

Student Panel

Study verified clinical cases, drug dosages, bookmarked cases, and clinical pearls.

Teacher Panel

Review case submissions, approve cases for students, provide feedback, and track learners.

Doctor Portal

Upload animal clinical records, symptoms, diagnosis, treatment, and pictures.

System Requirements

  • Node.js: v18.0.0 or higher (v20 LTS or v22 recommended)
  • NPM: v9.0.0 or higher
  • Operating System: Windows 10/11, macOS, or Linux (Ubuntu 20.04/22.04 LTS)
  • Browser: Modern browser (Chrome, Firefox, Safari, Edge)

Quick Installation Guide

Follow these 3 simple steps to get Vet Learn Hub up and running locally:

1. Extract the Zip file & open terminal in project directory:

cd vet-learn-hub

2. Install dependencies via NPM:

npm install

3. Create your .env file (or copy from .env.example):

cp .env.example .env

4. Start the server:

npm start

Or run in watch development mode: npm run dev

Default Access URLs:

  • Student Panel: http://localhost:3000/
  • Student Dashboard: http://localhost:3000/student/dashboard.html (Login: student@vetlearnhub.com / student123)
  • Teacher Panel: http://localhost:3000/teacher/login.html (Login: teacher@vetlearnhub.com / teacher123)
  • Doctor Portal: http://localhost:3000/doctor/login.html

Environment Variables

The application reads settings from the .env file in your root folder:

Variable Default Value Description
PORT 3000 The HTTP port Express listens on.
JWT_SECRET vet_learn_hub_... Secret string used to sign JWT tokens. Change in production!
TEACHER_EMAIL teacher@vetlearnhub.com Initial teacher account seeded on startup.
TEACHER_PASSWORD teacher123 Initial teacher account password.
GOOGLE_SCRIPT_WEB_APP_URL https://script.google.com/... Google Apps Script Web App endpoint for Google Drive uploads.

Google Drive Cloud Sync Setup

Vet Learn Hub supports uploading patient case images directly to your Google Drive folder. If Drive credentials are not supplied, the app automatically falls back to saving files in the local /uploads folder without crashing.

Recommended Method: Google Apps Script Web App (2 Minutes)

  1. Create a Google Drive folder and copy its Folder ID from the URL.
  2. Go to script.google.com and create a new project.
  3. Paste the Google Apps Script snippet located in config/google-apps-script.js.
  4. Click Deploy > New Deployment, select Web App, set "Who has access" to Anyone, and copy the Web App URL.
  5. Paste the URL into your .env file under GOOGLE_SCRIPT_WEB_APP_URL. Done!

Production Cloud Deployment

Deploying on Render.com (Free & Easiest)

  1. Push your repository to GitHub.
  2. Create a free account on Render.com.
  3. Click New + > Web Service and select your GitHub repository.
  4. Set Build Command: npm install
  5. Set Start Command: npm start
  6. Add your Environment Variables in the "Environment" tab.
  7. Click Deploy Web Service. Your app will be live within 2 minutes!

Frequently Asked Questions (FAQs)

Can I connect a SQL database like MySQL or PostgreSQL?

Yes! The data layer is cleanly isolated inside db/database.js. You can easily plug in Sequelize, Prisma, or Mongoose for MongoDB.

Do buyers need a paid Google Cloud account?

No! The Google Apps Script integration works on any free personal Google account with 15GB of free Google Drive storage.

How do I change the default admin credentials?

Update TEACHER_EMAIL and TEACHER_PASSWORD in your .env file or modify them directly in data/db.json.
